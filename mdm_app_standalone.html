स्थिती: तपासत आहे...
मोफत Google Firebase Realtime Database ची URL टाकल्यास सर्व डिव्हाइसेसवर ऑटोमॅटिक लाईव्ह सिंक होते.
💡 Firebase ला डेटा जाण्यासाठी काय करावे? (4 सोप्या पायऱ्या)
  1. Google वर Firebase Console उघडून Realtime Database तयार करा (Firestore नाही).
  2. डेटाबेसच्या Rules टॅबमध्ये { "rules": { ".read": true, ".write": true } } सेट करून Publish करा.
  3. डेटाबेसच्या वर दिसणारी URL (उदा. https://xxx-default-rtdb.firebaseio.com/) वरील बॉक्समध्ये पेस्ट करा.
  4. "🔍 Firebase कनेक्शन तपासा" दाबा व यशस्वी संदेश आल्यावर खालील "💾 सेव्ह करा व सुरू करा" बटण दाबा.
